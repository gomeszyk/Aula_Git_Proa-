# 🌱 Primeira aula de Git — Instituto PROA

Repositório criado durante uma atividade introdutória de **Git e GitHub** no Instituto PROA.

## 🎯 Objetivo

Praticar o fluxo básico de versionamento e registro de alterações em um repositório.

## 📚 Conceitos em estudo

- Diferença entre Git e GitHub.
- Repositórios e histórico de versões.
- Commits e mensagens de alteração.
- Envio de alterações para um repositório remoto.

## 🗂️ Sobre este repositório

É um exercício inicial de aprendizado. No momento, não contém uma aplicação executável — apenas a documentação da atividade.
